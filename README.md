# Мои дела

Личное Android-приложение для работы: люди, задачи со «следующими шагами», календарь, привычки, клиенты и заказы.
Данные хранятся только на телефоне. Интерфейс подстраивается под Galaxy Fold (сложен — один экран, развёрнут — два окна).

## Как установить
1. Откройте вкладку **Releases** этого репозитория на телефоне.
2. Скачайте последний файл `Moi-dela-N.apk` и откройте его.
3. При первой установке разрешите «Установку из неизвестных источников» для браузера.

Новые версии ставятся поверх старых — данные сохраняются.

## Этапы

- [ ] 2. Календарь, доска, личные дела
- [ ] 3. Привычки
- [ ] 4. Клиенты, заказы, база позиций, выгрузка в Excel

## Техника
Kotlin, Jetpack Compose (Material 3), Room. Сборка APK — GitHub Actions (`.github/workflows/build.yml`).
